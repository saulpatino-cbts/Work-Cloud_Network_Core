# Cloud Network & Security Assessment — Welcome Packet

> **Status**: Draft — update with finalized content from session 2026-03-05

## What Is This Assessment?

A read-only, non-intrusive discovery and analysis of your AWS and Azure network
architecture and security posture. We connect using least-privilege read-only
credentials you provide, collect topology and configuration data, and produce
a structured set of diagrams, findings, and recommendations.

## What We Deliver

- Architecture diagrams (draw.io, SVG, PNG) — VPC/VNet topology, security overlay, traffic flows, trust boundaries
- Executive summary with risk register and Zero Trust scorecard
- Technical recommendations mapped to CIS, AWS WAF, Azure WAF, NIST 800-207
- Regional reports (US, EMEA, Japan) with EN/JA language options
- 20-slide executive briefing deck (PPTX + PDF)
- Stakeholder delivery portal (password-protected static site)
- Knowledge transfer package with 30/60/90-day action checklist

## What We Do Not Do

- No changes to your environment
- No access to production systems beyond read-only API calls
- No assumptions — findings reflect only what we observed
- No deployment of infrastructure or IaC
