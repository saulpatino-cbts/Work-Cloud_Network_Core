# Direct Azure Evidence Guide

> Version: 1.0.0 | Status: Draft | Date: 2026-03-06

This guide describes the execution-oriented pass for direct Azure monitoring, telemetry, route, and certificate evidence collection.

---

## Added Controls

The platform now includes:
- direct Azure Monitor metric queries
- direct Application Insights telemetry queries
- direct Front Door route inspection
- direct Key Vault certificate evidence collection

---

## Design Intent

These changes begin the shift from modeled verification to command-executed platform evidence.
